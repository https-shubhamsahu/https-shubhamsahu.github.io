I build web and mobile applications, privacy tools, and interfaces for connected hardware. This directory connects each app to its project story, deployment, and public code or releases.

NO SUS / Nosus

NO SUS is my Android and web document-sharing project. Its work includes burn notes and files, selected Drive sharing, and a study vault. NO SUS Canary is a separate Monad testnet experiment that gives readers differently worded copies of a note.

Useful browser tools

VibeSplit tracks shared expenses and settlements. CertSecure explores certificate verification interfaces. Aurigen brings visual hardware programming into the browser.

What the links mean

Some applications are deployed experiments, some are prototypes, and M-Indicator 2.0 is an independent website concept. Each project page states its stage and links to verified websites.
