A project page should show its current state.

My latest portfolio note explains why live interfaces, hardware prototypes, and disconnected demos deserve clear labels.

7 Oct 2026 · LinkedIn + GitHub

Test one servo before debugging the gait.

My Aurigen C3 Rover build note starts with a small diagnostic for the ESP32-C3 and four SG90 servos.

The rover’s public documentation includes a separate servo diagnostic. With the robot lifted, each output can be checked using a known-good servo before calibrating centers and directions for the physical assembly.

This isolates the actuator and signal path before adding a complete walking sequence. The project page covers the firmware, OLED interface, BLE control, and the original hardware inspiration.
