14 Oct 2026 · GitHub

NO SUS 1.7.1: a focused Android app and a better PDF reader.

The Android release improves shared-document viewing, simplifies Send, and removes earlier experimental features, including the Web3 zone.

The public 1.7.1 release notes describe password prompts for locked PDFs and a shared reader with search, thumbnails, and dark pages. Send presents its available modes as single-select cards, while lists gain empty states and back gestures follow Android’s predictive back.

This release removes the receive address, nearby sharing, the group chat tab, Secure Pad, Focus time, and the Web3 zone from the Android app. The earlier NO SUS release notes below document those features historically. The standalone NO SUS Canary project on Monad testnet is a separate experiment.

The release also reports fixes to group-file deletion results, disconnected Google Drive accounts, and notification settings. These are changes documented by the release, rather than an independent Android compatibility or security assessment. Google Play installations should update through Google Play; the direct-install APK uses a different signing key.

12 Oct 2026 · GitHub

NO SUS 1.6.0: a new app design and Web3 zone.

This earlier Android release introduced a monochrome interface and a Canary experiment in the Web3 zone. The Web3 zone was removed in 1.7.1 on 14 October.

In 1.6.0, Home, Saved, Share, Groups, and Activity shared the redesigned NO SUS interface in light and dark themes. Its former Web3 zone included Canary notes: each reader receives an individually marked copy, with receipts recorded on Solana devnet, a public test network.

A matched copy is a clue about the copy that circulated; a reader-entered name does not establish a verified identity. This integrated Solana-devnet feature is distinct from the standalone Monad-testnet Canary project documented elsewhere in my portfolio.

The public release offers a direct-install APK. Google Play installations should update through Google Play: the two builds have different signing keys and cannot be installed over each other. Details and download options are in the public release notes.

12 Oct 2026 · GitHub

Packet Quest: learn networking one question at a time.

My browser study game turns Computer Networks revision into visual lessons, active-recall challenges, and exam-answer practice.

Packet Quest is built around the Mumbai University BE Semester V Computer Networks question bank. Its 24 missions cover network addressing and routing, transport protocols, and application-layer concepts, with short-answer and longer exam-writing prompts.

The game combines animated explanations, two challenges per mission, mistake review, a four-hour study plan, and a 20-mark mock. Progress stays in the browser. It is an independent revision aid; it does not promise exam results or replace the course material.

NO SUS 1.5.6: clearer Drop addresses.

The 8 October Android release improved Drop receiving addresses. This is a historical note: the Android receive-address feature was removed in 1.7.1 on 14 October.

A project page should show its current state.

My latest portfolio note explains why live interfaces, hardware prototypes, and disconnected demos deserve clear labels.

Test one servo before debugging the gait.

My Aurigen C3 Rover build note starts with a small diagnostic for the ESP32-C3 and four SG90 servos.

The rover’s public documentation includes a separate servo diagnostic. With the robot lifted, each output can be checked using a known-good servo before calibrating centers and directions for the physical assembly.

This isolates the actuator and signal path before adding a complete walking sequence. The project page covers the firmware, OLED interface, BLE control, and the original hardware inspiration.
