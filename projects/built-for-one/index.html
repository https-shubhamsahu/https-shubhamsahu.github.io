Built for One

Software stopped being a product. Doctors are next.

An interactive web essay by Shubham Sahu, written as a companion to a LinkedIn post, on what happens when building software gets cheap enough to make an app for one person.

Deployed interactive essay; the figures it cites come from public reporting, not my own research.

What I built

My dad is diabetic, and no company will build an app just for him. I wanted a page that lets people feel that shift instead of reading another thread about it.

  • Built four interactive scenes: an app for one person, AI writing a growing share of new code at Google, a clinic simulator with four doctors and too many patients, and India’s doctor gap.
  • Wrote the page as a single dependency-free HTML file with Canvas and SVG animation.
  • Published under shubham-sahu.me with cookie-free Cloudflare analytics and Google Analytics 4, covered by the site privacy notice.

Tools: HTML, CSS, JavaScript, Canvas, SVG.
