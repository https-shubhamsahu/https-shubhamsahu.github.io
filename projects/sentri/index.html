SENTRI

Visitor patterns, beyond an entry log.

A residential-security prototype combining visitor history, explainable trust scoring, and an ESP32-CAM edge unit.

Live product demo

What I built

A visitor register records entries but gives a guard little help spotting unusual repeat behavior.

  • Combined visit frequency, timing, host diversity, and repeat-denial patterns into a trust-score engine.
  • Built a dashboard for visitors, access events, anomalies, and edge devices.
  • Integrated an ESP32-CAM with a Flask/OpenCV console. The website uses demonstration data; no deployment or accuracy claim is inferred.

Tools: Next.js, React, Python, Flask, OpenCV, ESP32-CAM.
