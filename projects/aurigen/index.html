Aurigen

Blocks to firmware. All in the browser.

A visual programming workspace for ESP32 and Arduino: assemble blocks, inspect C++, simulate, then flash a real board.

Live browser workspace

What I built

Getting started with a microcontroller often means installing a toolchain before writing anything.

  • Connected Blockly to generated C++, a queued cloud compiler, and browser-based USB flashing.
  • Built an instant block interpreter and an AVR firmware simulation path.
  • Implemented ESP32 and Arduino flashing paths. Physical flashing requires compatible browser, hardware, and backend availability.
  • Co-founded Aurigen and helped run a hands-on ESP32 walking-robot workshop at TSEC in August 2026.

Tools: React, Blockly, Node.js, BullMQ, Redis, esptool-js.
