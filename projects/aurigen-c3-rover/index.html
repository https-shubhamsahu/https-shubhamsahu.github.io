Aurigen C3 Rover

Walking-robot firmware, one servo at a time.

An ESP32-C3 walking-robot firmware project by Shubham Sahu, combining four SG90 servos, OLED eyes, BLE commands, and a separate servo diagnostic.

Open-source firmware prototype; physical gait performance is not independently verified here.

What I built

A complete walking sequence can hide a wiring or actuator fault. The rover documentation starts with individual servo checks so the signal path can be tested before gait calibration.

  • Adapted walking-robot firmware for the ESP32-C3 SuperMini and HW566 expansion-board pinout.
  • Combined servo motion, expressive OLED eyes, BLE and serial commands, a buzzer, and optional Wi-Fi weather.
  • Documented a separate servo diagnostic and center/direction calibration for the physical assembly.
  • Adapted the hardware concept and workshop flow from thinking0things/AlbertMicro; the public README credits that inspiration.

Tools: ESP32-C3, C++, Arduino, BLE, I2C, SG90 servos.
