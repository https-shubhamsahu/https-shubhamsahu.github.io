R3Bin

AI-powered smart waste-sorting bin

An internship project connecting YOLOv8 waste detection, a touchscreen interface, and servo control through ROS 2.

Internship prototype

What I built

  • Connected camera classification, a PyQt5/QtWebEngine HMI, servo control, and an ESP32 hardware bridge.
  • Added a human correction flow and a hardware-free simulation harness.

Tools: ROS 2, Python, YOLOv8, PyQt5, Supabase.
