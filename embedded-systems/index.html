Embedded systems & programming
by Shubham Sahu.

I connect sensors and microcontrollers to interfaces people can use. My embedded work combines ESP32 firmware, sensor data, and web or mobile dashboards.

From hardware to data

Niva starts with an ESP32 and pressure sensors in an insole. Its dashboard makes the sensor readings and biomechanics rules inspectable. It is a working prototype, not a clinically validated device.

From visual blocks to firmware

Aurigen combines a browser block editor, generated C++, an ESP32 simulator, and a path to flashing real hardware. The project connects learning an idea to testing it on a board.

Tools I work with

ESP32, STM32, C/C++, FreeRTOS, I2C, UART, KiCad, and Web Serial. My project pages distinguish implemented features from prototype limitations.
