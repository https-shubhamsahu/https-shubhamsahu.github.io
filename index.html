01Product / software

NO SUS

Private sharing, with an expiry date.

An Android and web app for sharing documents, sending burn notes, and opening selected Drive files on a borrowed computer.

Project story ↗Visit nosus.foo ↗Open web app ↗Android releases ↗
Inside the build +

The problem

Sharing a file often means losing track of access. I wanted the sender to keep useful controls after sending it.

Live website · Android + web

What I built

  • Built a Flutter client and Supabase backend for document sharing, viewer-entered email watermarks, view limits, expiry, and access logs.
  • Added browser-encrypted burn notes and files, plus a phone-approved flow for opening selected Drive files on another computer.
  • Direct-link keys stay in the URL fragment; short pairing codes temporarily hold the key server-side. Watermarks provide an attribution clue, not verified identity.

Flutter / Dart / Supabase / Browser cryptography

02Hardware / software

Niva

From an insole to an understandable gait signal.

An ESP32 smart-insole prototype with a web dashboard, mobile app, and biomechanics rules that can be inspected.

Project story ↗Source ↗
Inside the build +

The problem

Sensor readings are only useful when you can explain how they become gait measurements.

Hardware + software prototype

What I built

  • Acquired pressure, piezoelectric, and MPU6050 telemetry using ESP32 firmware.
  • Implemented USB Serial and Wi-Fi WebSocket transport, a React dashboard, and a Flutter mobile app.
  • Calculated gait phase, cadence, center of pressure, and stability using explicit rules. The preview shows a disconnected prototype, not a clinical validation.
  • Showcased the prototype at Automation Expo in July 2026 with the project team.

ESP32 / React / Flutter / Web Serial / WebSocket

06Cryptography / experiment

NO SUS Canary

Different words. A traceable copy.

A Monad testnet experiment that gives each reader a differently worded note, then checks leaked text against those variants.

Project story ↗Visit shubham-sahu.me ↗Source ↗
Inside the build +

The problem

A leaked text copy can lose file metadata. Can the wording itself help identify its source?

Testnet experiment

What I built

  • Issued reader-specific linguistic variants and recorded opens on Monad testnet.
  • Built a paste-and-check flow for comparing leaked text with distributed variants.
  • The experiment traces a distributed copy through wording; it does not establish the identity of the person who shared it.

Monad Testnet / Solidity / Dart / Flutter / Cryptography
